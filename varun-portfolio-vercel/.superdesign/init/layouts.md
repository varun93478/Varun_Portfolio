# Layouts

## Root

`app/layout.tsx` supplies global metadata, local Geist fonts and the page body.

## Portfolio workspace

`StudioConcept` is a full-viewport application layout:

1. top workspace toolbar and tabs;
2. left navigation/project tree;
3. central zoomable canvas;
4. right project inspector;
5. bottom status bar and centered tool dock.

Varun OS will become the homepage layout and launch this existing workspace as a full-screen Work app.
