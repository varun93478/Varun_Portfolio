# Theme and tokens

## Typography

- Primary: local Geist variable sans.
- Technical labels: local Geist Mono variable.
- Minimum OS body copy target: 14px desktop; 15px mobile.
- Avoid microcopy below 11px except non-essential decorative coordinates.

## Existing workspace

- Surface: warm near-white.
- Chrome: neutral white/graphite.
- Accent: `#3155e7`.
- Borders: restrained neutral 1px rules.

## Varun OS extension

- Graphite: `#101214`.
- Deep graphite: `#080a0c`.
- Warm paper: `#f2f0e9`.
- Warm canvas: `#e9e6de`.
- Cobalt: `#3155e7`.
- Muted text: `#9da3aa`.
- Ready signal: `#79b85a`.

Use crisp borders, small radii and controlled shadows. Avoid glassmorphism, purple gradients and colorful desktop icon grids.
